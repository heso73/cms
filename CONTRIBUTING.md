# Contributing to the Caribbean Metadata Standard

The CMS is a regional common good. Contributions from Caribbean institutions, creators, researchers, and developers are welcome and essential.

## Evolution Process

| Step | Timeline | Who |
|---|---|---|
| Proposal submission | Day 0 | Any member |
| Public discussion (GitHub Issues) | 30 days | Community |
| Technical Committee vote | 15 days | Committee (2/3 majority) |
| Publication | 7 days | Secretariat |

---

## How to Propose a New Tag

1. Open an Issue with the title: `[TAG PROPOSAL] Family: Tag name`
2. Include:
   - **Family**: Linguistic / Cultural / Narrative / Rhythmic / Geographic / Socio-historical
   - **Proposed tag**: exact value
   - **Definition**: what does it describe?
   - **Territory or context**: where is it used?
   - **Example content**: 1–2 real examples of content this tag would apply to
3. The community discusses for 30 days
4. The Technical Committee votes

## How to Report an Error

Open an Issue with the title: `[CORRECTION] Field or section name`

Describe the error and the expected correction.

## Code Contributions

Pull requests are welcome for:
- Bug fixes in conversion tools (`cms_to_dublin_core.py`, `cms_to_ebucore.py`)
- New conversion tools (e.g., CMS → IPTC, CMS → PBCore)
- Improvements to the template or documentation

Please open an Issue before submitting a large PR.

---

## Code of Conduct

This project follows a simple principle: **respectful, constructive dialogue**. Contributions that demean, exclude, or harm Caribbean communities or their cultural heritage will not be accepted.
